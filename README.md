# Task & Project Management Dashboard

A modern, responsive Task and Project Management Application built with **Next.js**, **TypeScript**, **Tailwind CSS**, and **Supabase**. Features a sleek dashboard interface with custom Dark/Light mode support.

---

##  Features

**Project Management**: Create, list, and delete projects with custom color tags.
**Task Management**: Create tasks with priority levels (*Low, Medium, High*), due dates, and statuses (*Pending, Completed, Overdue*).
**Team Assignments**: Assign specific tasks to project members dynamically.
**Filtering & Search**: Instantly filter tasks by status, category, or project.
**Dynamic Theming**: Full Dark/Light theme integration using CSS variables.
**Responsive Design**: Mobile-friendly sidebar drawer and backdrop modals.

---

## 🛠️ Tech Stack

**Framework:** [Next.js](https://nextjs.org/) (App Router)
**Language:** [TypeScript](https://www.typescriptlang.org/)
**Styling:** [Tailwind CSS](https://tailwindcss.com/)
**Backend & Database:** [Supabase](https://supabase.com/) (PostgreSQL)
**Icons:** [Lucide React](https://lucide.dev/)
